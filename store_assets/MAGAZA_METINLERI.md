## Privacy practices (Gizlilik uygulamaları)

**Single purpose (Tek amaç):**

```
Hekimin onayladığı klinik görüşme taslağını, hekimin kendi açık hastane bilgi sistemi oturumundaki muayene ve istem formlarına aktarmak.
```

**storage izni gerekçesi:**

```
Hekimin Klinot hesap bağlantısını ve form doldurma hızı tercihini tarayıcıda saklamak için.
```

**tabs izni gerekçesi:**

```
Aktarımın yalnızca hekimin açık hasta kartı sekmesinde yapılması ve doğru sekmeyi bulmak için.
```

**Host permission (site erişimi) gerekçesi:**

```
Taslağı aktarmak için hastane bilgi sistemi sayfalarına, taslağı almak için Klinot sunucusuna erişir. Başka hiçbir siteye erişmez.
```

**Remote code (uzaktan kod):** "No, I am not using remote code" seç.
